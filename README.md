# GPT From Scratch

A GPT-style language model built from scratch using PyTorch.

This project follows Andrej Karpathy's "Let's build GPT: from scratch, in code, spelled out" tutorial while implementing and experimenting with the core components of a Transformer-based language model.

## Goals

- Understand tokenization
- Build a basic language model
- Implement self-attention
- Implement multi-head attention
- Build Transformer blocks
- Train a small GPT-style model
- Experiment with model architecture and training
